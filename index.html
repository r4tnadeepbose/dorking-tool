Authorized Use Only. Use these searches only against domains you own or have explicit permission to test. Generates search links for reconnaissance; does not scan or exploit systems.

Target & Options

Domain/hostname (no scheme). Examples: example.com, *.example.com. Use {target} in custom dorks.
If a line does not include site: or {target}, site:{target} is prepended automatically.
Operators & filters cheatsheet
site:
Limit results to a domain or host.
Examplesite:example.com
inurl: / allinurl:
Match keyword(s) in the URL.
Exampleinurl:login
intitle: / allintitle:
Match keyword(s) in the page title.
Exampleintitle:"index of"
intext: / allintext:
Match keyword(s) in page body text.
Exampleintext:"api_key"
filetype: / ext:
Filter by file extension/type.
Examplefiletype:pdf
"phrase"
Match an exact phrase.
Example"internal use only"
OR | ( ) -
Combine, group, or exclude terms.
Examplelogin | signin -help
*
Wildcard placeholder (engine-dependent).
Examplesite:*.example.com
cache:
View cached page (Google; may be limited/unavailable).
Examplecache:example.com
Operator support varies by search engine. Use for authorized recon only.
