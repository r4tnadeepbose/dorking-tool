Clear Cache / Fix Cache Error

This page helps clear browser-side caches for the Dorking Tool (local app). If you see a cache error or the UI looks different/stale, follow these steps.

Ready.

Manual steps (recommended)

  1. Restart the server: stop python run.py / python server.py (Ctrl+C) and start it again.
  2. Hard refresh: open http://127.0.0.1:8765/ and press Ctrl+F5 (or Ctrl+Shift+R).
  3. Clear site data: DevTools (F12) → Application → Storage → Clear site data for 127.0.0.1:8765.
  4. If needed: open in a private/incognito window, or clear cached images/files for this site in browser settings.

Note: Clearing site data may remove local app state (projects/history/settings) stored in browser localStorage for this origin. Export important data first if needed.
